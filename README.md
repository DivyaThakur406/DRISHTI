# 🚨 DRISHTI

## Disaster Response Intelligence & Situational Tracking Interface

DRISHTI is an AI-assisted disaster response and situational awareness platform designed to transform scattered emergency information into structured, prioritized, and actionable intelligence.

The platform provides a centralized interface for analyzing incidents, verifying information, prioritizing emergencies, coordinating emergency resources, supporting citizens, and monitoring disaster situations.

---

## 🎯 Problem Statement

During disasters, critical information is often scattered across multiple channels such as citizen reports, emergency alerts, field reports, weather information, news sources, and other communication channels.

This creates several challenges:

- Difficulty identifying genuine incidents
- Duplicate and conflicting reports
- Delayed identification of critical emergencies
- Lack of centralized situational awareness
- Difficulty prioritizing incidents
- Inefficient emergency resource allocation
- Delayed coordination between responders
- Difficulty tracking the overall disaster situation

DRISHTI addresses these challenges through an integrated disaster intelligence and response coordination platform.

---

# 💡 Our Solution

DRISHTI combines AI-assisted incident analysis, incident verification, emergency resource coordination, citizen reporting, geospatial awareness, and disaster analytics into a centralized Emergency Command Center.

The system converts incoming emergency information into structured incident intelligence and helps responders make faster and more informed decisions.

💻 Installation & Setup
Prerequisites

Make sure the following are installed:

Python 3.10 or newer
Git
VS Code or another Python-compatible IDE

Check your Python version:

python --version

If python does not work on Windows, try:

py --version
📥 Clone the Repository

Clone the repository using:

git clone YOUR_GITHUB_REPOSITORY_URL

Then enter the project directory:

cd DRISHTI-SIH

Replace YOUR_GITHUB_REPOSITORY_URL with the actual GitHub repository URL.

🐍 Create a Virtual Environment

Create a virtual environment:

python -m venv venv
Windows
venv\Scripts\activate
macOS / Linux
source venv/bin/activate

After activation, you should see:

(venv)

at the beginning of your terminal.

📦 Install Dependencies

Install all required packages:

pip install -r requirements.txt

The main dependencies include:

streamlit
pandas
numpy
plotly
🚀 Run the Application

Start DRISHTI using:

streamlit run app.py

The application will normally be available at:

http://localhost:8501

Open the URL in your browser.

In a production deployment, the aggregation layer can be connected to authorized external data sources and emergency-response infrastructure.
